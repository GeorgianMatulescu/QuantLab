# Migración v0.6 a v0.7

Conserva:

- `data/`
- `Python/Config/settings.yaml`
- `MATLAB/Reports/`
- `logs/` opcionalmente

Procedimiento:

1. Renombra la versión anterior.
2. Sube la nueva carpeta QuantLab.
3. Copia `data/`.
4. Copia `Python/Config/settings.yaml`.
5. Copia `MATLAB/Reports/`.
6. Ejecuta `main`.
7. Ejecuta `launch_dashboard`.
8. Ejecuta el test de dashboard.
